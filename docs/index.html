Mermaid NG — Visual Editor

A WYSIWYG, drag-and-drop visual editor for AI-friendly Mermaid diagrams, right inside VSCode. Built for software architects and developers who design systems faster when they can see what they're building — and round-trip every diagram back into the .md or .mmd files it lives in.

● WYSIWYG ● Drag-and-drop ● Fully offline ● No telemetry ● Multi-sheet ● Mermaid 10.9.0 bundled ● MIT

Why Mermaid NG?

Mermaid is the lingua franca for diagrams in modern engineering and AI workflows — it's text, so LLMs love it, Git diffs cleanly, and it renders everywhere. But writing the text by hand is slow and reading a complex diagram is painful. Mermaid NG closes the loop with a WYSIWYG canvas that is the Mermaid source.

👁️

WYSIWYG — what you see is what you get

Every change on the canvas updates the Mermaid source in real time, and every keystroke in the code pane re-renders the canvas. They're the same thing.

🖱️

Drag-and-drop palette

Process boxes, decisions, subroutines, databases, hexagons, edges, subgraphs, sequence actors, ER entities, class members, state transitions — drag onto the canvas.

🌐

Fully offline

Mermaid 10.9.0 is inlined. The extension makes zero network requests at runtime. No telemetry. No cloud. Works on air-gapped machines.

📑

Multi-sheet (draw.io style)

Every ```mermaid block in a markdown file becomes its own tab. Each sheet has its own undo history. Add, rename, remove sheets inline.

🤝

AI-friendly

Mermaid is text, so paste any LLM's diagram, refine it visually, paste back. No format conversion, no PNG round trips, no fidelity loss.

💾

Round-trips Markdown in place

Save back rewrites only the diagram blocks in your .md file — surrounding prose, code fences, frontmatter are preserved.

🪝

Click to connect, double-click to edit

Drag from one node onto another to wire them up — the right edge syntax is picked per diagram family. Double-click for labels, styles, colors, members.

↶

Full undo / redo

Cmd/Ctrl+Z, Cmd+Shift+Z / Ctrl+Y. Captures every visual mutation — drag, modal apply, delete, type — per sheet.

🖼️

SVG / PNG export

Native save dialog, default filenames derived from the diagram title: or active sheet name, so multi-sheet exports stay distinguishable.

🗑️

Hover to delete

Hover any node or edge and press Delete / Backspace, or hit the red Delete button in the edit modal. Undoable.

🎨

12+ diagram families

Flowchart, sequence, class, state, ER, gantt, pie, journey, mindmap, gitgraph, timeline, quadrant — all in the same editor.

🔒

Private by design

No accounts, no analytics, no opt-outs needed. Your diagrams never leave your machine.

See it in action

Drag, double-click, edit, save back — all inside VSCode, all fully offline.

Commands

All commands live under the Mermaid NG category in the VSCode command palette.

CommandDescription
Mermaid NG: Open Visual Editor Opens an empty visual editor in a new panel.
Mermaid NG: Open Visual Editor with Selection Seeds the editor with the current text editor selection.
Mermaid NG: Open Mermaid Diagrams from File Scans the file. One diagram opens directly; multiple diagrams show a thumbnail picker that opens all of them as sheets, with the clicked one active.
Mermaid NG: Insert Current Diagram into Active Editor Inserts the active sheet's code at the cursor (or replaces the selection) in the focused text editor.
Mermaid NG: Save Diagram Back to Source File Bound to Cmd/Ctrl+S while the panel is focused. Rewrites every sheet back into the source file, or opens a Save As dialog for scratch panels.

Install

Released as a .vsix on GitHub. Marketplace publication is in progress.

From the GitHub release

# Download the latest .vsix
curl -LO https://github.com/NextGenPowerToys/mermaid-visual-editor/releases/latest/download/mermaid-visual-editor-1.0.0.vsix

# Install it into VSCode
code --install-extension mermaid-visual-editor-1.0.0.vsix

From source

git clone https://github.com/NextGenPowerToys/mermaid-visual-editor.git
cd mermaid-visual-editor/vscode-extension
npx @vscode/vsce package --allow-missing-repository
code --install-extension mermaid-visual-editor-1.0.0.vsix

For development

Open vscode-extension/ in VSCode and press F5 to launch an Extension Development Host with the extension loaded.

Getting started

Two ways to start drawing.

📄

Edit an existing diagram

Right-click any .md, .mdx, .markdown, .mmd, or .mermaid file in the explorer and pick Mermaid NG: Open Mermaid Diagrams from File. Single-diagram files open directly; multi-diagram files show a thumbnail picker first.

✨

Start a new diagram

Open the command palette and run Mermaid NG: Open Visual Editor for a scratch panel. Hit Cmd/Ctrl+S when you're done — a Save As dialog will create a new .md (or .mmd) for it.
